# 🛒 Online Shopper Purchasing Intention Prediction

An end-to-end Machine Learning project designed to predict whether an online shopper is likely to make a purchase based on their browsing behavior.

## 📌 Project Overview

Online shopping platforms generate a large amount of customer browsing data. Understanding customer behavior can help businesses identify users who are more likely to make a purchase.

This project uses Machine Learning to analyze customer browsing behavior and predict purchasing intention.

### 🎯 Objective

The main objective of this project is to:

* Predict whether a customer will make a purchase.
* Analyze online browsing behavior.
* Identify important features influencing purchasing intention.
* Build an interactive web application for real-time prediction.

---

## 📊 Dataset

The project uses the **Online Shoppers Purchasing Intention Dataset**.

The dataset contains information about customer browsing sessions and includes features such as:

* Administrative Pages
* Administrative Duration
* Informational Pages
* Informational Duration
* Product Related Pages
* Product Related Duration
* Bounce Rates
* Exit Rates
* Page Values
* Special Day
* Month
* Operating System
* Browser
* Region
* Traffic Type
* Visitor Type
* Weekend

### Target Variable

**Revenue**

* `1` → Customer made a purchase
* `0` → Customer did not make a purchase

---

## 🤖 Machine Learning Model

The project uses a Machine Learning classification model to predict customer purchasing intention.

The model analyzes customer browsing information and produces a prediction:

* ✅ **Likely to Purchase**
* ❌ **Not Likely to Purchase**
